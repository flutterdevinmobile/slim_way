## ✨ Key Features

- 🤖 **AI Nutrition & Fitness Assistant:** Conversational AI coach providing personalized meal plans, macro breakdowns, and healthy-living advice.
- 🔥 **Smart Calorie & Macro Calculator:** Dynamic daily calorie, protein, carb, and fat targets tailored to user body metrics and weight goals.
- 💧 **Hydration & Activity Tracking:** Interactive water intake logger, step counter integration, and workout session tracking.
- 📊 **Visual Progress Analytics:** Weekly and monthly weight, calorie, and macro adherence charts with smooth animations.
- 🌍 **Multi-Language Support:** Full localization (uz, u, en) and dark/light theme support.

## 🏗️ Architecture & Tech Stack

- **Mobile Client:** Flutter, Dart, BLoC / Cubit, Clean Architecture, GoRouter
- **Backend Server:** Serverpod (Full-Stack Dart Backend), PostgreSQL
- **Local Persistence:** Hive / SharedPreferences for offline-first resilience
- **Networking & AI:** Serverpod RPC client, REST APIs, LLM Assistant integration
